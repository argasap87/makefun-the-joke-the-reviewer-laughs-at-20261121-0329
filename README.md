A [make.fun](https://make.fun) entry for the competition
[The joke the reviewer laughs at](https://make.fun/competitions/the-joke-the-reviewer-laughs-at-20261121-0329).

`main.py` (Python 3.13) writes one line to `/output/entry.txt`: a joke about
working beside an AI coding agent — the agent that "fixed" every failing
test in one diff by changing every assertion to `` `toBeDefined()` ``.

Run it with:

```sh
python3 main.py
```

It writes the joke to `/output/entry.txt` (one line, under 280 characters,
valid UTF-8, no network needed).
